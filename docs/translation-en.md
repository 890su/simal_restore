# Проверка английского каталога

Дата: 7 ноября 2026. Результат — явные исправления в
`data/translations-reviewed-en.json`. Исходный архив и нормализованный каталог
в ходе этой редакторской задачи не перезаписывались.

## Охват

- В исходном снимке 425 товаров с непустым английским названием. Проверены
  424 действительные записи; повреждённый тестовый товар `13538` исключён из
  перевода и остаётся выключенным правилом качества основного импортёра.
- У 255 записей название и доступные характеристики сверены с русской записью
  **того же ID**. Остальные 169 имеют собственные английские архивные ID:
  проверены язык, единицы и читаемость существующего текста, без склейки с
  похожими русскими товарами.
- Все 38 уже существовавших английских описаний заменены короткими связными
  версиями по доступному источнику. Для них подготовлены законченные summary,
  вместо обрезанных посреди слова фрагментов. Отсутствующие длинные описания
  не создавались.
- Проверены английские названия всех 37 категорий. Например, категория
  «Банкетки и пуфы» теперь `Benches and ottomans`.
- Наименования 18 типов характеристик и конечный словарь материалов, цветов,
  стран и единиц переведены явно. Числа размеров и суффиксы моделей сохранены;
  отдельный тест сравнивает числовые токены всех названий, сверенных с RU.

Это языковая и редакторская проверка восстановленного содержимого. Она не
подтверждает текущие спецификации поставщика, цены, наличие, гарантии или
соответствие фотографий. Сохраняются исходные флаги коммерческой проверки и
конфликтов идентичности.

## Существенные исправления

| ID | Было в EN | Исправление по RU того же ID |
|---|---|---|
| 9758 | ODRI 1400, ширина 153 cm | ODRI 1600, ширина 173 cm |
| 9759 | PRIMA 1600, спальное место 160×200 | PRIMA 1400, спальное место 140×200 |
| 9771 | ELITE 1200, ширина 120 cm | ELITE 1600, ширина 160 cm |
| 9786 | HARD 180×200 | EXTRA HARD 900 |
| 9789 | Топпер LUX 160×200 | Подушка LUX, размеры 48×68 cm |
| 10364 | Шкаф SIRIUS 2 | Комод SIRIUS 4 с его собственными размерами |
| 10991 | IMPERIAL 1800, ширина 180 cm | IMPERIAL 800, ширина 80 cm |
| 11202 | IMPERIAL 900, ширина 90 cm | IMPERIAL 1200, ширина 120 cm |

Эти ошибки возникали из-за эвристического сопоставления разных языковых
карточек. Исправлялись переводимые поля; ID, SKU, категории, цены и архивные
свидетельства не менялись. Глобальные рекламные обещания и машинные обрывки
вроде `A banquet`, `wrong purposeonly`, `Attentionathletic` в новых кратких
описаниях не используются.

Коды производителя `МДК`, `МД`, `Б-` и исходное написание моделей сохраняются.
Кириллица внутри такого кода не считается непереведённым обычным словом.

## Неразрешённые исходные противоречия

- Для ELITE `13587` и `13588` исходный EN одновременно указывает общую высоту
  4 cm и слой пены 50 mm. Неподтверждённая толщина не перенесена в исправленные
  характеристики; описание предлагает уточнить наполнитель и толщину в магазине.
- У `9819` русское название — HARD 1800, а исходное описание называет EXTRA HARD.
  Название следует выбранной нормализованной RU-записи; краткое описание не
  повторяет спорное имя модели. Требуется проверка владельцем каталога.
- У `9753`, `9818`, `10363`, `10378`, `10840` в архиве есть разные названия для
  одного ID. Языковая редактура не разрешает этот конфликт идентичности.
- Для английских карточек без RU того же ID характеристики не подтверждены
  заново поставщиком. Технические утверждения исходника не превращаются в
  независимо проверенные факты.

## Подключение к сборке

```text
импорт архива/Google CSV
→ node scripts/apply-translation-reviews.mjs
→ извлечение контента и подготовка публичного каталога
→ сборка сайта
```

Скрипт по умолчанию читает обе существующие проверки
`data/translations-reviewed-en.json` и `data/translations-reviewed-ka.json`,
проверяет все ID и поля и атомарно записывает результат в normalized JSON.
Для проверки без записи:

```powershell
node scripts/apply-translation-reviews.mjs --check
node --test tests/translation-reviews.test.mjs
```

Если `catalog.source.type === "csv"`, текст из Google Таблицы считается
приоритетным: архивные product/category overrides **не применяются**. Это
защищает последующие ручные правки владельца от старого review-файла. В отчёт
попадает `skipped: csv_source_authoritative`. При первом экспорте таблицы
редактура применяется к архивному снимку до создания итогового CSV/XLSX.

Для действительных активных товаров с названием и отсутствующим URL скрипт
подготавливает `/en/product/<id>/` и `/ge/product/<id>/`. Для переведённых
нескрытых категорий без URL — `/en/catalog/<categoryId>/` и
`/ge/catalog/<categoryId>/`. Имеющиеся канонические URL и `legacyUrls`
сохраняются. Неактивные записи и `invalid_title` не получают новые маршруты.

`reviewedFields` перечисляет фактически проверенные поля. Флаг машинного
перевода снимается только при покрытии всех заполненных полей языка; частичная
проверка остаётся частичной. Заметки редактора не копируются в публичный товар.
**Ни скрипт, ни review-флаги не устанавливают robots/noindex.**

Скрипт `scripts/prepare-en-review-data.mjs` воспроизводит конкретный редакторский
набор из сохранённых словарей и текстов. Он не является шагом production-сборки:
при изменении исходного ассортимента новые записи нужно проверять отдельно.

## Проверки

Девять тестов покрывают запрет изменения коммерческих полей и неизвестных ID,
отделение частичной проверки от полной, отсутствие редакторских заметок в
товаре, URL только для действительных переводов, обработку категорий,
идемпотентность, коллизии URL, приоритет Google CSV и реальные исправления
ошибочных названий/размеров. Числовые токены source-aligned названий совпадают
с RU-источником. Проверка `--check` обоих EN/KA файлов прошла без записи.
