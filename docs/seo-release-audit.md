## Индексация и языковые версии

- `robots.txt` разрешает обход сайта, исключает `/api/` и указывает `https://simal.ge/sitemap.xml`. В sitemap 894 уникальных адреса, ровно по одному для каждой страницы без `noindex`. Сопоставление URL учитывало процентное кодирование. В sitemap нет адресов страниц с `noindex` и URL с незакодированными пробелами.
- На всех 1 180 страницах есть один canonical на `https://simal.ge`. Проверка соответствия канонического пути файлу сборки прошла для обычных маршрутов. Служебная 404 исключена из сравнения пути и отсутствует в sitemap.
- Проверены 3 503 ссылки `hreflang` в 315 группах. У всех страниц в группах совпадают наборы альтернатив, есть ссылки на себя и обратные ссылки. Все цели существуют в сборке и разрешены к индексации. `x-default` на 873 страницах указывает на русскую альтернативу той же группы. У 21 страницы такой альтернативы нет. Google описывает `x-default` как необязательный вариант для остальных языков. [Google Search Central о языковых версиях](https://developers.google.com/search/docs/specialty/international/localized-versions).
- `noindex` есть у 286 страниц. На 242 карточках это следствие отсутствия исходной карточки, описания и параметров. Остальные случаи включают служебные страницы, архивные акции, пустые категории и информационные заглушки. Язык и флаг редакторской проверки не закрывают товарные переводы. Условия проверены в [catalog.ts](D:/aibrain/04_projects/simal-ge/src/lib/catalog.ts:133).
