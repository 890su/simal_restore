# Перенос контента и SEO

Состояние на 7 ноября 2026. Это локальный аудит восстановленной копии, а не подтверждение индексации production или позиций в поиске.

`node scripts/extract-content.mjs` воспроизводимо создаёт `data/pages.json` и `data/seo-migration.json` из сохранённого `site/`. Исходный архив не изменяется. Извлечена 21 информационная страница/страница акций/индекс новостей на русском и английском. Полных грузинских информационных страниц в текущем архиве нет.

## Контракт данных

`pages.json` содержит `{pages:[{path,lang,title,description,heading,kind,html,images,needsReview,reviewReasons,sourcePath}]}`. `html` разрешено выводить через `set:html` только после этого импортёра. Используется allowlist семантических тегов; стили, классы, обработчики, скрипты, старые формы, SVG, iframe и удалённые изображения не переносятся. Изображения включаются только при наличии локального файла; заглушки не выдаются за восстановленные фотографии.

`needsReview` обозначает редакторскую проверку: архивные акции, переводы и страницы с коммерческими условиями/контактами. По уточнению владельца переводы проверяются и исправляются, но не закрываются от индексации только из-за языка или этого флага. Для акций нужен видимый статус «Архивная акция» и отсутствие обещания действующей скидки. Исключение из sitemap/hreflang и `noindex` допустимы для архивной акции или конкретных неподтверждённых коммерческих условий, но не для самого факта перевода. News — восстановленный индекс заголовков; исходные статьи преимущественно отсутствуют, их тексты не сгенерированы.

## Подтверждённые проблемы

- В главной странице «Компания» и условиях доставки сохранился старый адрес в Тбилиси (Церетели, 101), а отдельная страница контактов содержит Гурамишвили, 17 Б. Не объединять эти сведения и не обозначать оба адреса действующими; контактная страница — приоритетный источник для отображения, требуется проверка владельца.
- Политика конфиденциальности описывает регистрацию и персонализацию старого сайта. Её нужно согласовать с новой реальной обработкой заявок, localStorage и уведомлениями; сохранённый документ не является готовым юридическим текстом новой версии.
- Архивные акции датированы 2023–2026 годами и не подтверждают текущие скидки.
- Найдена посторонняя ссылка `/aktsii/abonement-fitnes-za-4900-rub-god/`: не переносить и не перенаправлять на мебельный каталог.
- Локальный отчёт содержит 360 маршрутов, на которые ссылается архив, но для которых нет сохранённого `index.html`. Это не HTTP-проверка production: часть может восстановиться импортом, остальные требуют точного соответствия или корректного 404.
- У шести страниц отсутствует/не соответствует пути canonical. Полный список — `canonicalIssues` в JSON. Существующие hreflang в локальных файлах не ссылаются на отсутствующие локальные пути; это ограниченная проверка, она не подтверждает качество переводов и взаимность всех пар.

## Правила новой версии

1. Сохранять существующие товарные/категорийные адреса там, где есть реальный контент. Дубли одной модели переводить точным 301 на канонический товар только по доказанному соответствию ID и варианта.
2. Генерировать self-canonical из фактического маршрута, а не из старого HTML. Для языковых страниц self-canonical сохраняет свой язык; не канонизировать всё на русскую главную.
3. Hreflang только между реально опубликованными эквивалентами, с self-ссылкой и взаимностью. Код грузинского языка `ka`, каталог URL может остаться `/ge/`. Восстановленный перевод проверяется редакционно; язык и translation-review flag сами по себе не исключают страницу.
4. Sitemap содержит только опубликованные indexable canonical-страницы с HTTP 200. Не включать корзину, wishlist, API, preview и страницы фильтров. Переводы не исключать только из-за неполной редакторской проверки.
5. Для исчезнувшего товара не делать массовый редирект на главную. Сохранять полезную карточку с актуальным статусом либо возвращать 404/410; точный аналог — отдельное подтверждённое соответствие.
6. Не публиковать неизвестную цену как ноль и не использовать непроверенное наличие для Product/Offer. Не добавлять вымышленные отзывы/рейтинги/сроки гарантии.
7. До выпуска проверить JSON-LD в готовом HTML и браузере, canonical/sitemap/robots, внутренние ссылки и mobile UX. Этот аудит не использовал Rich Results Test, Search Console или field Core Web Vitals.

При обработке отчёта `missingLinkedRoutes` не создавать пустые SEO-страницы автоматически. Первая очередь восстановления — товарные карточки, главные категории и полезные статьи с подтверждённым исходным содержанием.
