Файлы: `site/images/recovered/<ID>-yandex.jpg`. Все шесть открыты через инструмент просмотра изображений. Это уменьшенные изображения; полное разрешение не восстановлено и не имитировалось увеличением. Снимок Gannover показывает диван с открытым ящиком и не является постановочным первым ракурсом.

Полный provenance сохранён в `data/image-recovery.json`: `originalUrl`, `cacheUrl`, `sourcePageUrl`, `retrievedAt`, фактические `dimensions`, размеры источника по поисковому индексу и SHA-256 полученных байтов. Метод — существующий `yandex-thumbnail`, без изменения схемы импортёра.

Ограниченный поиск: три успешных запроса Yandex (`site:simal.ge Gannover`, `site:simal.ge мебель`, `site:simal.ge кровать`) дали 62 записи Simal, из которых шесть исходных URL точно совпали с имеющимися кандидатами. Пять дополнительных запросов по отдельным моделям завершились транспортной ошибкой; повторного бесконечного обхода не было. Google вернул HTML без доступных thumbnail-байтов. Результаты Bing не использованы. Фото PRIMA, ODRI и ARIZONA этой попыткой не восстановлены.

Проверка выполнена через `normalizeArchive` в памяти: все шесть записей приняты штатным валидатором, прочитаны обратно с `sourceType: recovered-yandex-thumbnail` и `resolution: thumbnail`; SHA-256 локальных файлов совпадают с manifest. `data/normalized-catalog.json` при этой проверке не перезаписывался: основной импорт и этап проверки переводов выполняет финальная сборка.
