# SIMAL — статическая копия simal.ge

Копия публичного сайта [simal.ge](https://simal.ge/) из Wayback Machine (снимок около 20 мая 2026). Живой сайт в момент сборки не отвечал.

Папка для публикации: `site/`.

## Что внутри

- Главная, каталог, кровати, диваны, матрасы, акции, контакты, оплата и доставка, о компании, блог, сотрудничество, версии `/en/` и `/ge/`.
- Вёрстка шаблона Bitrix (цвета, шапка, сетка, мобильные стили) и часть фотографий, которые были в архиве.
- Кнопка «В корзину» и формы заявки открывают WhatsApp `+995 571-10-05-15`, потому что сервер Bitrix больше не принимает заказы.

## Чего в архиве не было

Не все карточки товаров и не все фото попали в Wayback. У части товаров на главной картинка может не открыться. Корзина, личный кабинет и поиск по серверу не работают: это был PHP-сайт Bitrix.

## Публикация на Cloudflare Pages

Из этой папки:

```bash
npx wrangler pages deploy site --project-name simal
```

Нужен вход в Cloudflare (`npx wrangler login`). Домен simal.ge потом подключается в панели Pages как custom domain, когда DNS снова под вашим контролем.
