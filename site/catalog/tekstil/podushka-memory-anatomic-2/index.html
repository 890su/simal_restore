Подушка Memory Anatomic из инновационного материала Memory Foam с памятью формы. Подушка эргономичной формы с валиками различной высоты позволяющими подобрать наиболее комфортное положение головы и шеи при сне на боку либо спине. При этом создавая анатомически правильную поддержку во время сна. Наполнитель подушки — высокоэластичная пена c эффектом памяти Memory Foam, которая точно повторяет контуры головы и шеи, реагируя на тепло и оказываемое давление. Когда давление пропадает, пена постепенно восстанавливает первоначальную форму. Высокоэластичная пена c эффектом памяти имеет сертификат соответствия CertiPUR, который свидетельствует об экологичности и безопасности продукции. Такие подушки устойчивы к пылевым клещам. Внешний съёмный чехол выполнен из двухслойной трикотажной ткани. Подушка упаковывается в удобный чехол-переноску (в виде коробки или в виде сумки). Подушка Memory Anatomic - полное расслабление и максимальный комфорт! ЧЕХОЛ ПОДУШКИ Элитное трикотажное полотно с высоким содержанием вискозы. Лицевая часть ткани имеет шелковистую поверхность с ткацким рисунком. Ткань с отличной циркуляцией воздуха Прованс. Чехол съемный. Чехол можно стирать. Антистатичен.
